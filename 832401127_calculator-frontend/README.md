# Calculator Frontend
Frontend client for calculator system, separate from backend.

## Tech Stack
HTML + CSS + Vanilla JavaScript

## How to run
Open index.html in browser directly.
Or use VSCode Live Server plugin to preview.

## Backend config
Default backend address: http://127.0.0.1:8000/api
Change BACKEND_URL in app.js if backend deployed to other address.

## Functions
1. Input expression and send request to backend for calculation
2. Show calculation result and error message
3. Fetch and display calculation history from backend
4. Delete single history record
